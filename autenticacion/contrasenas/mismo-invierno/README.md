# Mismo Invierno, Nuevo Año

## Descripción general

Desafío educativo orientado a trabajar conceptos introductorios de ciberseguridad mediante una dinámica tipo *Capture The Flag (CTF)*.

Esta descripción es intencionalmente **genérica**: no incluye pasos de resolución ni spoilers. La fundamentación pedagógica completa se encuentra en la documentación del proyecto.

---

## Dinámica del desafío

El participante debe analizar evidencia visual provista en el desafío; inspeccionar un archivo adjunto en un entorno simulado; utilizar scripts provistos para preparar o reproducir el escenario y aplicar razonamiento crítico para identificar información relevante y obtener la *flag* (sin incluir spoilers ni pasos de resolución).
